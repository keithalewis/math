These notes provide a brief history of AI with a view to understanding
how to use large language models effectively. A LLM is a function from
strings to strings parameterized by a context. This is a correct, but useless, statement.

A user can type in a
string of text and get a string of text back. Different LLM's, or
the same LLM at a later time, may give different results.
Every LLM has a _context_ determined by training data and a training
algorithm.

..._hyper parameters_, which sounds better than hard coded "magic" numbers into software

...Low wage workers from third-world countries

The most important thing to know about LLM's is their output cannot be trusted.
LLM's do not create anything. They scrape existing data off the internet and
make unwarranted assumptions about its correctness. You should only use
them for topics you already have some knowledge of. It is your responsibility
to do further research on suspicious replies.

LLM's are tools for creating new things.
If the LLM has the information you are after you can help it zero in by
cutting down the context with questions from general to specific.
