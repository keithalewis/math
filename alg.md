## Binary Operation

$m\colon S\times S\to S$.

_commutative_ if $m(a,b) = m(b,a)$ for $a,b\in S$.

## Semigroup

A set with an associative binary operation.

$m\colons S\times S\to S$ with $m(m(a,b)c) = m(a,m(b,c))$.

$(ab)c = a(bc)$ so $abc$ has unique reading

## Group

A semigroup with inverse elements.

For every $g\in G$ there exist $g'$ with $gg' = e$.

Show $g'$ is unique.

Show $g'g = e$

Multiplicative $g^{-1}$, additive $-g$.

## Ring

Additive abelian group, multiplicaive semigroup, left and right distributive
$a(b + c) = ab + ac$ and $(a + b)c = ac + bc$.

Ring with unity multiplication is a monoid.

## Domains

### Integral Domain

Commutative ring with identity where $ab = 0$ implies $a = 0$ or $b = 0$.

Allows cancellation.
